# Винила-ванила

Цифровая полка коллекции виниловых пластинок: добавление по фото и поиску (MusicBrainz),
трек-листы, биографии (Wikipedia), полные треки во встроенном плеере, NFC- и QR-метки на конвертах.
Работает бесплатно, без ключей и серверов: это одна веб-страница.

## Как выложить на GitHub Pages (бесплатно, 5 минут, без программ)

1. Зайдите на https://github.com и зарегистрируйтесь (бесплатно), если ещё нет аккаунта.
2. Справа вверху «+» → **New repository**.
   - Repository name: `vinila-vanila`
   - Выберите **Public** (бесплатные GitHub Pages работают только с публичными репозиториями).
   - Нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file**
   (или **Add file → Upload files**).
4. Перетащите в окно ВСЕ файлы из этой папки: `index.html`, `manifest.webmanifest`, `sw.js`,
   `icon.svg`, `icon-192.png`, `icon-512.png`, `.nojekyll`, `README.md`. Внизу нажмите **Commit changes**.
   > Если `.nojekyll` не виден в проводнике (файл без имени) — ничего страшного, сайт заработает и без него.
5. Откройте **Settings** (вкладка репозитория) → слева **Pages**.
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)** → **Save**.
6. Подождите 1–2 минуты и обновите страницу Pages. Вверху появится адрес вида
   `https://ВАШ-ЛОГИН.github.io/vinila-vanila/` — это ваше приложение.

## Проверка на телефоне (Android, Chrome)

1. Откройте адрес в Chrome.
2. Меню ⋮ → **Установить приложение** (или **Добавить на главный экран** → **Установить**).
   Приложение откроется на весь экран, без адресной строки, и появится в списке приложений телефона.
   > Если иконка была добавлена раньше и открывается как страница браузера — удалите её
   > с главного экрана и установите заново.
3. Откройте «Группа крови» → **▶ Поставить на вертушку**. Должен заиграть полный трек
   во встроенном плеере. Если телефон не запустил звук сам, нажмите ▶ прямо в окне видео.

## NFC-метка

Теперь метку можно записать прямо из приложения:
карточка пластинки → 🏷 → вкладка NFC → **Записать на метку** → приложите метку к телефону.

Или вручную через NFC Tools, запись типа URL:

```
https://ВАШ-ЛОГИН.github.io/vinila-vanila/#r=VV3
```

(`VV3` — код «Группы крови»; код любой пластинки виден в окне 🏷.)

## Важно

- Коллекция хранится в памяти браузера на этом телефоне. Пластинки, добавленные
  в версии на claude.ai, сюда не переносятся — добавьте их заново.
- Полные треки ищутся через открытые серверы Piped (поиск по YouTube Music).
  Они бесплатные, но иногда отключаются — тогда играет 30-секундный фрагмент из Apple Music.

## Как обновить приложение

В репозитории: **Add file → Upload files** → перетащите новые файлы (одноимённые заменятся)
→ **Commit changes**. Через 1–2 минуты сайт обновится; в установленном приложении
закройте его и откройте снова.
